# Fresh-vegetables-
Fresh Veggie Online Grocery Store - Complete Updated Package

## Features Included:
1. **Customer Address Auto-Save**: Address ek baar daalne par auto-save ho jata hai aur agli baar direct dropdown me dikhta hai. Sath me "+ Add New Address" ka option bhi hai.
2. **Cloud Firestore Sync**: Orders customer place karte hi live Firebase Firestore me save hote hain.
3. **Payment Modes**:
   - Cash on Delivery (COD)
   - Dynamic QR Code (UPI) with 12-digit UTR/Txn ID field
   - Customer Wallet support
4. **Secret 5-Tap Admin Mode**: Header me 🥦 logo par 5 baar tap karne se Admin Panel unlock hota hai.
5. **Firebase UID Verification**: Admin UID check hone par real-time order dashboard unlock hota hai.
